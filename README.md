# 🚗 DVLD Management System

A comprehensive desktop application built with **C#**, **Windows Forms**, **SQL Server**, and **ADO.NET** to simulate the operations of a real-world **Driving & Vehicle License Department (DVLD)**.

The system manages drivers, licenses, users, and driving-related services through a layered architecture while applying software engineering best practices.

---

## 📖 Overview

The DVLD Management System is designed to automate the daily operations of a Driving & Vehicle License Department. It provides a secure and organized environment for managing people, drivers, users, license applications, tests, and licensing services.

This project was developed to strengthen practical skills in desktop application development, database design, object-oriented programming, and layered architecture.

---

## ✨ Features

### 👤 User Management

* Add, update, delete, and search users
* Manage user accounts and permissions
* Secure authentication system

### 👥 People & Driver Management

* Register and manage people records
* Create and manage driver profiles
* Store and update personal information
* Track driver history

### 🪪 License Management

* Issue new driving licenses
* Renew expired licenses
* Replace lost or damaged licenses
* Manage different license classes
* View license history

### 📋 Application Management

* Local driving license applications
* International driving license applications
* Application status tracking

### 📝 Driving Tests

* Schedule vision, written, and practical tests
* Manage test appointments
* Record test results

### 🚓 Detained License Services

* Detain licenses
* Release detained licenses
* View detention history

### 🔐 Authentication & Authorization

* Secure login system
* Username and password validation
* Permission-based access control

### 🗄 Database Integration

* SQL Server relational database
* Data access using ADO.NET
* Efficient CRUD operations
* Data validation and integrity

---

## 🏗 Architecture

The project follows a **3-Tier Architecture**:

* Presentation Layer (Windows Forms)
* Business Logic Layer (BLL)
* Data Access Layer (DAL)
* SQL Server Database

This architecture improves maintainability, scalability, and separation of concerns.
