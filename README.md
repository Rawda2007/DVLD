# 🚗 DVLD Management System

A full desktop management system built with C# and Windows Forms to simulate real-world Driving & Vehicle License Department operations.

## 📖 Overview

DVLD (Driving & Vehicle License Department) System is a desktop application designed to manage drivers, licenses, users, and driving-related services through an organized and user-friendly interface.

The project focuses on applying real software engineering concepts including layered architecture, database management, authentication, validation, and CRUD operations.

---

# ✨ Features

## 👤 User Management
- Add new users
- Update user information
- Delete users
- Search users
- Manage permissions and accounts

## 🚘 Driver Management
- Register drivers
- Store personal information
- Track driver records

## 🪪 License Services
- Issue licenses
- Renew licenses
- Replace lost licenses
- Release detained licenses
- Manage license classes

## 🔐 Authentication System
- Secure login system
- Username & password validation
- Access control for users

## 🗄 Database Integration
- Connected with SQL Server
- Efficient data handling using ADO.NET
- Stored and managed relational data

## 🎨 User Interface
- Clean Windows Forms UI
- Easy navigation between forms
- Organized menus and controls
